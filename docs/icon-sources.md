# Tool icon sources

The dashboard bundles these marks locally so the binary renders without a
runtime network request. Brand names and marks remain the property of their
respective owners.

- Cursor, Claude, Windsurf, TRAE, GitHub Copilot, Hugging Face, LM Studio and
  Ollama: [Simple Icons v16.31.0](https://github.com/simple-icons/simple-icons),
  downloaded from the pinned jsDelivr package. Simple Icons is released under
  CC0 1.0.
- OpenAI mark used by Codex CLI, OpenAI Desktop and ChatGPT Desktop:
  [SVGL OpenAI asset](https://svgl.app/library/openai.svg).
- Continue: [official Continue repository logo](https://github.com/continuedev/continue/blob/main/docs/logo/light.svg).
- Antigravity: [Google Antigravity press assets](https://www.antigravity.google/press),
  represented by the [MIT-licensed monochrome SVG](https://thesvg.org/icon/antigravity-google).

The generic `llm` tool has no single vendor mark, so it uses the normal initial
fallback.
